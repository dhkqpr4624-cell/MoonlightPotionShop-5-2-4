## 2. 창구·제작대 PNG 전체 표시

- **이전 문제**: 창구 장면을 화면에 꽉 차게 키워(cover) 위·아래가 잘렸습니다.
- **지금**: 창구 3장과 제작대 1장 모두 원본 비율 그대로, 위·아래·좌·우가 다 보이게(contain) 맞춥니다. 비율이 다르면 바깥에 가게 나무 톤의 단색 여백(`#231812`)이 생깁니다. 음수 위치로 밀어 자르는 일은 없습니다.
- 크기는 상단 상태 바를 뺀 실제 장면 상자를 재서 계산합니다(`ResizeObserver`). 100vh를 가정하지 않습니다.
- **같은 좌표계**: 배경·손님·덧문은 창구 캔버스(1672×941) 하나의 배율 안에서 움직입니다. 제작대의 서랍·항아리·병 받침·책·주문서 버튼과 물약 SVG는 모두 PNG 픽셀 좌표(`src/data/shopArt.ts`의 `WORKBENCH_SCENE`)에서 같은 함수로 화면 좌표로 바꿉니다. 포인터 좌표도 같은 식으로 거꾸로 바꿔 항아리 안(타원) 판정을 하므로, 여백이 생겨도 그림과 클릭 영역이 어긋나지 않습니다.
- **창구**: 주문서·포션 받침·버튼(HTML)은 테이블 윗면부터 아래에 놓입니다. 테이블 그림 높이가 모자란 화면(태블릿 세로 등)에서는 그 아래 여백까지 씁니다. 손님 크기는 기존 외형별 설정을 쓰되, 장면이 작아진 만큼 함께 작아지고 귀 끝이 장면 위쪽·대사창에 걸리지 않게 맞춥니다.
- **덧문**: 그래픽·움직임·속도·영업 상태 연결·효과음은 그대로입니다. 창 개구부 상자 안에서 열리고 닫히는 구조도 그대로이며, 장면 배율만 따라갑니다.

## 3. 탑뷰 제작대

| 자리 | 내용 |
|---|---|
| 맨 왼쪽 위 서랍 | 기력초 더미(무제한 공급원, 재고 줄지 않음). 다른 서랍은 비워 둠 |
| 가운데 항아리 | 안쪽 타원 `pot.inner`(650, 594, 반지름 200×176)으로 잘라 그리는 물약. 금속 테두리·손잡이는 덮지 않음. 기본 용액(옅은 청록) → 기력초를 넣으면 파문과 함께 연두색 → 저을수록 기력 포션 색(청록 `#3fc79a`)으로. 막대를 잡으면 막대 끝 잔물결, 소용돌이 회전, 작은 입자(개수 고정) |
| 젓는 막대 | 끝은 액체 속, 손잡이는 위쪽으로 뻗음. 잡아서 움직이는 방식 그대로(젓기 버튼 없음), 키보드 ←→도 그대로 |
| 오른쪽 병 받침 | 병에 담은 포션이 칸에 놓임(6병까지 그림, 그 이상은 ‘모두 N병’) |
| 돌판 위 | ‘병에 담기’·‘창구로 가져가기’ 버튼 |
| 왼쪽 아래 | 레시피북 PNG + 위쪽 HTML 글자 ‘레시피’ |
| 오른쪽 아래 | 주문서 PNG + 위쪽 HTML 글자 ‘주문서’ |
| 계량 패널 | 넓은 화면: 항아리와 주문서 사이(병 받침 위)에 겹침. 세로 화면: 제작대 아래 |

- 책·주문서는 항아리·병 받침·돌판과 겹치지 않는 빈 바닥 자리에 두었습니다(화면 크기 6종에서 자동 확인).
- 기존 솥·선반 그래픽은 올리지 않습니다. 기존의 ‘주문 메모·레시피북’ 접이식 패널은 두 팝업으로 대체했습니다.

### 책 모양 팝업 (`src/components/BookPopup.tsx`)

- 두 팝업 모두 책 패널 PNG를 배경으로 쓰고, 동시에 하나만 열립니다. 글자는 HTML로 양쪽 종이 안쪽에만 놓습니다(가운데 접힘선·장식·책 바깥을 피함). 길면 그 종이 안에서 스크롤합니다.
- **레시피**: 제목 ‘레시피’, 포션 이름·설명, 1병당 기력초 0.6g, 기본 용액 자동 안내, 해금 상태
- **이번 주문**: 손님이 한 원래 말, ‘네?’ 쉬운 설명(이미 ‘네?’를 눌렀으면 펼쳐진 채로), 주문 내용(포션·병 수·배수·특별 조건), 지금 필요한 일
- 저장된 주문 데이터만 읽고, 새 대사를 만들지 않습니다. 기본 화면에는 식·정답이 없습니다.
- 닫기 버튼·Esc·책 바깥 누르기로 닫힙니다. 바깥 누르기는 click으로 닫으므로 뒤쪽 항아리에 전달되지 않습니다. 닫으면 연 버튼으로 초점이 돌아갑니다. 열려 있는 동안 초점은 팝업 안에서만 돌고, 뒤쪽 조작과 키보드 숫자 입력은 막힙니다.
- 계량·젓기 중에도 열 수 있고, 입력 중인 답과 진행은 그대로입니다. 끌던 재료·잡던 막대는 열리는 순간 안전하게 놓습니다(젓기 소리도 멈춤). 팝업이 열려 있는지는 저장하지 않습니다.

### 기력초 옮기기

- ① 서랍 클릭 → 항아리 클릭, ② 서랍에서 끌어 항아리에 놓기, ③ 터치 탭·터치 끌기, ④ 키보드 — 모두 같은 게임 행동(`PLACE_INGREDIENT`)입니다.
- 집은 상태(‘집음’ 표시), 끄는 동안 포인터를 따라오는 기력초, 항아리 놓을 곳 점선(위에 오면 강조)을 보여 줍니다.
- 항아리 밖에 놓으면 상태가 바뀌지 않고 서랍으로 돌아갑니다. 계량 중·완료 재료는 막고, 두 번째 손가락은 무시합니다. 끈 뒤 따라오는 click은 한 번 무시합니다(두 번 처리 없음).

## 4. 기력 포션과 한 재료 규칙

- 기력 포션: 기력초 1종, **1병당 0.6g**, 기본 용액 30mL는 무료·자동(계량 문제 아님). 여러 병 주문은 기존 2~9병.
- 새로 만드는 주문은 기력 포션만 씁니다. 별빛·용기·새싹·안개는 `legacy`로 남겨 저장 호환에만 씁니다.
- 기본 레시피 문제에서 0.6g은 바꾸지 않습니다. 다른 인수 구조는 **손님 지정량 주문**(`customAmount`)으로 분명히 나눕니다. 원래 대사·쉬운 설명·주문서·힌트·해설이 모두 손님이 정한 양을 씁니다.
- ‘재료는 항상 두 개’라는 가정을 찾아 없앴습니다.
  - 완료 판단은 그 주문의 재료 과제 수로 합니다.
  - 생활 소재·비교 주문은 레시피의 재료 수에 맞춰 만들고, 다른 재료가 없으면 ‘다른 재료는 기본량’ 문장을 넣지 않습니다.
  - 비교 문제의 질문·단위(“기력초 … g”)와 계량 단위 안내도 재료에서 만듭니다.

### 한 재료로 지원하는 학습 유형 (모두 지원, 우회 없음)

| 유형 | 주문 종류 (후보 수) | 실제 예 (게임에서 만든 주문) |
|---|---|---|
| ① 소수 한 자리 × 자연수 | 여러 병 8, 생활 소재 8 | “기력 포션 2병이요. 가방에 딱 2칸이 비어 있어요!” → 0.6 × 2 = 1.2g |
| ② 소수 두 자리 × 자연수 | 손님 지정량(1병당) 48, 생활 소재 8 | “기력 포션 2병 주세요! 저는 기력초를 1병에 0.15g씩만 넣어야 기운이 딱 맞아요.” → 0.15 × 2 |
| ③ 자연수 × 소수 한 자리 | 손님 지정량(기준 양) 64, 생활 소재 3 | “우리 집 비법에서는 기력초를 2g 넣는데, 오늘은 그 0.2배로 부탁해요.” → 2 × 0.2 |
| ④ 자연수 × 소수 두 자리 | 손님 지정량(기준 양) 48, 생활 소재 3 | “… 기력초를 2g 넣는데, 오늘은 그 0.15배로 …” → 2 × 0.15 |
| ⑤ 소수 한 자리 × 소수 한 자리 | 맞춤 배수 8, 생활 소재 3 | “제 컵이 아주 작아서 기본 레시피의 0.2배로만 만들어 주세요.” → 0.6 × 0.2 |
| ⑥ 소수 두 자리 × 소수 한 자리 | 손님 지정량(기준 양) 48, 생활 소재 3 | “… 기력초를 0.15g 넣는데, 오늘은 그 0.2배로 …” → 0.15 × 0.2 |
| ⑦ 곱의 변화 비교 | 비교 75 | “지난번 특별 포션에는 기력초를 0.6 × 3 = 1.8g 넣었대요. 이번에는 6 × 3g로 …” → 10배 고르기 |

- 학습 단계마다 그날 소개되는 유형을 낼 수 있는지 테스트로 확인했습니다(빠진 유형 없음).
- 기본 수 범위(자연수 2~9, 소수 한 자리 0.2~2.5, 소수 두 자리 0.12~1.25)는 그대로입니다.

### 판매금 (재료 과제 수와 정확한 과제 수 기준)

- 모든 재료 정확 100%, 일부만 정확 80%(재료 2개 이상일 때만 생김), 정확한 재료 없음 60%. 정수, 소수 부분 버림.
- 기력 포션(과제 1개): **정답 100%, 오답 60%**. 힌트·‘네?’는 감액하지 않습니다.
- 이전 레시피(2재료) 주문을 마칠 때는 원래대로 100·80·60%입니다.

### 집계

- 하루 계산 문제 수는 실제 과제로 셉니다. 기력 포션 하루는 **5문제**입니다(10으로 고정하지 않음). 지정량 과제는 계산 문제 수에서 뺍니다.

## 5. 재료 해금 (`src/game/unlocks.ts`)

- 재료 ID·해금 비용은 `src/data/ingredients.ts`에, 레시피별 필요 재료 ID는 `src/data/recipes.ts`의 첨가물에 있습니다.
- 해금한 재료 목록은 저장 버전 4의 `unlockedIngredients`입니다. 레시피는 필요한 재료를 모두 해금했을 때만 새 주문 후보가 됩니다(`isRecipeAvailable`, `availableRecipes`). 레시피를 따로 사지 않습니다.
- 구매(`tryUnlock`, 리듀서 `UNLOCK_INGREDIENT`)는 내부 데이터의 가격만 씁니다.
  - 잔액 부족·이미 해금·없는 재료·이전 버전 재료는 아무것도 바꾸지 않습니다(중복 차감 없음).
  - 영업 중에는 사지 않습니다.
- 기력초는 무료로 처음부터 해금되어 있고, 기력 포션도 처음부터 쓸 수 있습니다. 돈이 없어도 첫 영업을 시작할 수 있습니다.
- 학습 유형 소개 단계와는 별개입니다. 단계가 올라도 재료가 저절로 해금되지 않습니다.
- 영업 마감 화면의 **재료 해금** 메뉴에는 기력초 ‘사용 가능’, 기력 포션 ‘사용 가능’, 그리고 “지금은 새로 해금할 재료가 없어요”가 나옵니다. 가짜 상품은 없습니다.
- 구매·여러 재료 레시피 해금은 **테스트 전용 카탈로그**로만 검사했습니다(`tests/energy.test.ts`). 게임에는 노출되지 않습니다.
