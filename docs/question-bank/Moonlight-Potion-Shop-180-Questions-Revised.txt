달빛 포션 상점 소수의 곱셈 문제은행 — 180문항
인코딩: UTF-8 / 하·중·상 각 60문항 / 각 난이도에서 세 곱셈 유형 각 20문항

[사용 규칙]
1. 이 문항은 손님 지정량 특별 주문이다. 기존 레시피의 고정 기본량을 수정하지 않는다.
2. operand_a와 operand_b는 십진 문자열이다. 인수만 소수 두 자리 이하이며 정답은 소수 네 자리까지 가능하다. 반올림하지 않는다.
3. 각 레코드는 재료 하나의 계산 과제다. 전체 주문의 다른 필수 재료는 해당 레시피의 정상 조건으로 별도 구성하고 모두 투입해야 완성한다. 잠긴 재료·레시피 문항은 출제하지 않는다.
4. question은 기본 문제, clarification은 ‘네?’ 재설명, hint는 주문서의 힌트, explanation은 오답 확정 후 해설이다. 기본 화면에 식·정답을 노출하지 않는다.
5. 소수×자연수는 여러 병 주문, 나머지는 한 병의 배수 특별 주문이다. g과 mL의 단위 변환은 없다.
6. 난이도는 계산 부담 기준이다. 하: 한 자리 소수 중심, 중: 두 자리 소수 또는 중간 자연수, 상: 두 자리 자연수 또는 두 자리 소수끼리의 곱.
7. 바람 정령의 파편 등의 명칭은 기준 프로젝트의 기존 ID에 연결한다. 이름이 유사하다고 새 재료를 만들지 않는다.
8. 정답 문자열의 끝 0 유무는 판정에 영향을 주지 않는다. 0.5=0.50으로 인정한다.

[개정 사항 — 주문 대사 개선판]
- 180개 ID·난이도·포션·재료·인수·정답·병 수를 원본 그대로 유지했다.
- 기본 대사는 포션을 주문하는 말로 끝낸다. ‘몇 g이오?’, ‘총량을 알려 주시오’ 같은 계산 질문은 제거했다.
- 모든 주문에 포션명·병 수·지정 재료·기준량·병당 또는 배수 조건을 명시했다.
- 배수 주문은 지정 재료만 바꾸고 나머지는 레시피 한 병 분량임을 명시했다.
- 재설명은 주문 조건만 쉬운 말로 전달한다. 식은 힌트에서만 공개한다.
- 수학 내용은 유지하고 힌트·해설의 일부 조사 표현을 정리했다.
- 이 파일 밖의 게임 자체 대기 대사·주문 템플릿도 별도 점검해야 한다.
