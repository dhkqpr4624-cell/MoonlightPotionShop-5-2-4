기준: 첨부하신 정상 작동 Phase 4 프로젝트(`MoonlightPotionShop-5-2-4-main.zip`)와 `달빛 물약 상점 png.zip`.
게임 규칙·주문·문제·계산·힌트·해설·품질·판매금·학습 기록·복습·저장 기능과 제조대는 바꾸지 않았습니다.

## 1. 적용한 PNG

PNG는 **내용을 바꾸지 않고**(바이트 단위로 동일함을 확인) 웹 주소에 쓰기 쉬운 영문 이름으로 복사만 했습니다.
파생 파일(잘라 낸 전경·마스크 등)은 만들지 않았습니다. 창구가 이미 세 장으로 나뉘어 있어 필요가 없었습니다.

## 2. 화면 구성

겹침 순서(뒤 → 앞): **마을길 → 손님 → 기존 덧문 → 아치 → 테이블 → 대사창·주문서·버튼(HTML)**

- 창구 캔버스는 **늘리지 않고** 같은 비율로 키워 화면을 덮고, 남는 바깥쪽만 잘립니다(태블릿 세로에서는 양쪽 선반이 잘리고 창 부분이 보입니다).
- 캔버스의 테이블 윗면이 화면의 주문서·버튼 영역 윗면과 정확히 같은 높이가 되게 맞춥니다. 주문서·받침·버튼은 테이블 그림 위의 HTML입니다.
- 손님은 창밖에 서서 아치 창 안에 보이고, 하반신은 테이블에 가려집니다.
- 이전 SVG 창구 배경(`NightBackdrop`: 벽·등불·별 반짝임)은 PNG와 겹치지 않게 지웠습니다. 포션 받침(`tray.svg`)은 PNG에 없는 전달 위치라 그대로 둡니다.

### 손님 표시 설정 (`src/data/appearances.ts`, 외형마다 따로)

- `scale`(크기), `cutY`(카운터에 닿는 높이), `centerX`(몸 중심), `top`(실제 귀 끝), `headY`(얼굴 높이)
- 토끼는 귀가 길어 머리가 작아 보이므로 조금 크게(0.54) 했습니다. 귀 끝이 화면 위쪽·아치 곡선·위쪽 대사창에 걸리면 그 화면에서만 크기를 줄입니다. 서 있는 기준선(카운터)은 그대로입니다.
- 원본 PNG의 실제 크기(1205~1206 × 1305~1306)를 그대로 써서 비율이 바뀌지 않습니다.
- 넓은 화면: 손님은 창의 왼쪽, 대사창은 얼굴 옆. 좁은 화면(900px 미만): 손님은 가운데, 대사창은 위쪽.

### 움직임

- 등장·퇴장: 기존 연출을 PNG 전체에 그대로 적용했습니다.
- 호흡: 그림 전체를 같은 비율로 아주 조금만 움직입니다(가로·세로 같은 배율, 찌그러짐 없음).
- 만족·아쉬움·불만족: 기존 대사와 간단한 움직임(깡충·끄덕·살짝 내려앉기)만 씁니다. 표정을 덧그리거나 PNG를 찌그러뜨리지 않습니다.
- 꼬리·귀를 잘라 따로 움직이지 않았고, 예전 SVG 꼬리도 붙이지 않았습니다.
- 손님 PNG를 읽지 못하면 4단계 코드 그림으로 대신 보여 주고 게임은 계속됩니다.

## 3. 덧문 (기존 그대로 + 위치만 맞춤)

유지: 덧문 그림(판자·보강목·달/별 구멍·경첩), 열림·닫힘 움직임과 속도(0.9초, 기존 지연 그대로), 영업 상태 연결, 마감 후 닫힌 상태, 다음 날 열림, 새로고침 복구, 효과음.

조정한 것 (`src/components/art/Shutters.tsx`):
1. 덧문이 보이는 범위(viewBox)를 덧문 두 짝 크기(x150~850, y60~560)로 바꾸고, 아치 PNG의 창 개구부 상자 안에 넣었습니다. 비율은 늘리지 않고 맞춥니다(가장자리 약 1%만 잘림).
2. 예전 SVG 아치 모양 잘라내기와 창틀 다시 그리기를 뺐습니다. 이제 아치 PNG가 덧문 앞에서 창틀 역할을 해 중복 창틀이 생기지 않습니다.
3. 덧문은 손님 앞, 아치 뒤에 놓입니다. 닫히면 개구부 전체(아치 꼭대기까지)를 가리고, 열린 덧문은 아치 기둥 뒤로 사라져 손님을 가리지 않습니다.

## 4. 저장 호환

- 손님 ID(fox·rabbit·cat·wolf)와 대사는 그대로입니다.
- 주문에 선택 항목 `appearanceId`를 더했습니다. 새 주문을 만들 때 정해 저장하므로 새로고침해도 같은 손님입니다.
- 외형은 문제를 고르는 난수와 섞지 않고 주문 번호로만 정합니다. 그래서 같은 시드면 문제·손님 순서가 이전과 똑같고, 외형과 난이도는 관계가 없습니다. 같은 종족이 연달아 오면 바로 앞과 다른 외형을 씁니다.
- `appearanceId`가 없는 이전 저장의 주문은 손님 ID별 기본 외형으로 항상 같게 보입니다. 저장을 고치거나 지우지 않습니다.
- 저장 버전은 3 그대로입니다. 가져오기 검사에서는 없는 외형이나 다른 종족의 외형을 거부합니다.
- 하루 손님 5명, 주문 생성 규칙, 도감·해금은 바꾸거나 추가하지 않았습니다.

## 7. 남은 제한

- 손님 PNG는 장당 약 1.2~2.1MB, 창구 3장은 합쳐 약 4.9MB라 처음 열 때 학교 와이파이에서 조금 느릴 수 있습니다. 화면에 나오는 손님만 내려받고, 그날 손님 그림은 미리 읽어 둡니다. 더 가볍게 하려면 같은 이름의 WebP나 작은 PNG로 바꿔도 됩니다(코드 변경 없이 경로만).
- 태블릿 세로에서는 화면 비율상 양쪽 선반이 잘리고 창 부분만 보입니다(그림을 늘리지 않기 위해서).
- 타이틀 화면 배경과 제조대는 4단계 SVG 그대로입니다.
