- **칸 수**: 필요한 새 재료 12종(칠흑의 밤꽃 포함) + 기존 3종 = 15칸. 기존 제작대 그림의 서랍은 14칸(위 6 + 아래 8)이고 빈 칸은 11칸뿐이라 **1칸 모자랐습니다**. 최소 조정으로 제작대 왼쪽의 빈 그릇(막자사발 옆)을 15번째 칸으로 썼습니다. 모든 테마 제작대 그림에 같은 자리에 그릇이 있습니다.
- 이전 버전 재료(달빛 이슬·별가루)는 진행 중이던 옛 주문이 있을 때만 아래 7·8칸을 잠시 빌려 보입니다.
- **추천 순서(다음 목표)**: 부족한 재료가 가장 적은 레시피, 같으면 싼 쪽. 거인(오거) → 바람 걸음(깃털풀·파편) → 산호빛(은백합) → 샘물약(수액) → 매의 눈(사파이어) → 강철(호두) → 폭풍(산호·비늘) → 태양(용 비늘·유황석) → 그림자(밤꽃·진액·정령 가루). 잠긴 서랍에 금빛 테두리와 ‘다음 목표’, 레시피북에 “다음 목표: …”로 보여 줍니다. 다른 순서로 사도 됩니다.
- 해금한 레시피는 그날 주문을 바꾸지 않고 다음 날부터 나오며, 첫날 최소 1건을 보장합니다. 만들 수 없는 레시피 주문은 생기지 않습니다.
